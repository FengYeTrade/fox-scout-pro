# FOX SCOUT PRO · 佛伯乐数字足迹侦察兵

> 对标「AI小蔡狗」佛伯乐利器，比它更强的开源桌面版：**真实特征提取引擎 + 六维暴露评分 + 泄露自查 + 分级防护清单 + 可选大模型深度分析**。
> 运行环境：Windows / macOS / Linux 桌面程序（EXE 一键运行），不是纯前端假把式。

## 这是什么

输入你自己的 **邮箱 / 手机号 / 用户名**，程序在本地做真实的数字足迹分析：

| 能力 | 说明 | 是不是假的 |
|---|---|---|
| 本地特征引擎 | 邮箱域名信誉分级（主流/一次性邮箱真实列表）、手机号段→运营商/归属地真实映射、用户名模式识别（年份/纯数字/姓名拼音/平台句柄）、熵计算 | ✅ 真实规则，非随机 |
| 六维暴露评分 | 账号暴露 / 密码习惯 / 公开资料 / 社交痕迹 / 位置暴露 / 设备指纹，每维 0–100 | ✅ 确定性公式，可复算 |
| 综合暴露指数 | 0–100，高危 / 中危 / 低危 + 风险解释 | ✅ |
| 泄露自查 | 内置真实公开泄露事件库（CSDN、12306、网易邮箱、京东、AcFun、微博、Facebook、LinkedIn 等 10+ 起公开事件）本地模拟匹配 | ✅ 本地离线匹配 |
| 分级防护清单 | 按维度动态生成 P0（立即）/ P1（尽快）/ P2（建议）行动项 | ✅ |
| 大模型深度分析 | 填任意 OpenAI 兼容 API Key（DeepSeek / OpenAI / Kimi / 通义等），把本地侦察结果交给大模型做攻击面分析与修复建议 | ✅ 真实联网调用，不填 Key 完全离线 |
| 报告导出 | TXT / HTML 双格式，含全部侦察明细 | ✅ |

## 合规声明

- 本工具**只分析你自己输入的信息**，用于个人隐私自查与防护，不连接任何社工库、不提供任何第三方查询能力。
- 泄露自查为**本地模拟匹配**（基于公开新闻报道的事件名与年份做字符串匹配），不代表你的账号确实出现在这些事件中，请以官方渠道核实。
- 请勿用于查询、监控或攻击他人。

## 下载与运行

- Windows：下载 `FOX_SCOUT_PRO.exe`（本仓库 Release），双击即用，无需安装 Python。
- macOS / Linux：`python3 fox_scout_pro.py`（需 Python 3.8+，`pip install PySide6`）。

首次使用点「启动侦察」，输入格式示例：

```
test@example.com 13800138000 alice2024
```

## 大模型分析怎么用

1. 完成侦察 → 切到「大模型分析」页签
2. 填入 API Key（DeepSeek 等，OpenAI 兼容格式）
3. 点「开始大模型深度分析」→ 程序把本地侦察结果（六维评分 + 泄露命中 + 特征事实）发送给模型，返回攻击面分析与加固建议

不填 Key 时，本地引擎照常工作，完全离线。

## 自己打包 EXE

```bash
pip install pyinstaller pyside6
pyinstaller --onefile --windowed --name FOX_SCOUT_PRO fox_scout_pro.py
# 产物在 dist/FOX_SCOUT_PRO.exe
```

## 引擎说明（六维模型）

| 维度 | 依据 |
|---|---|
| 账号暴露 | 邮箱域名信誉、一次性邮箱、短账号、用户名熵 |
| 密码习惯 | 用户名含年份/姓名+数字、纯数字、低熵 |
| 公开资料 | 用户名含姓名拼音、手机号尾号特征、平台句柄 |
| 社交痕迹 | 平台关键词（wxid/微博/QQ号等） |
| 位置暴露 | 手机号归属地、区号特征 |
| 设备指纹 | 平台前缀、系统特征、低熵标识 |

综合指数 = 加权平均（账号 22% / 密码 20% / 公开资料 18% / 社交 12% / 位置 18% / 设备 10%）。
