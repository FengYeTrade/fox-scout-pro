FOX SCOUT PRO

个人数字足迹自查工具（Windows 桌面版）。输入你自己的邮箱、手机号、用户名，在本机分析暴露风险，生成报告。不连接任何社工库。

下载 Windows 版（52.8 MB）
双击即用，无需安装 Python。源码见 GitHub 仓库。

能做什么

  • 邮箱域名信誉分级（主流 / 一次性邮箱识别）
  • 手机号段 → 运营商、归属地
  • 用户名模式识别（年份 / 纯数字 / 姓名拼音等）
  • 六维暴露评分与综合暴露指数
  • 泄露自查（本地匹配公开泄露事件库）
  • 可选接入大模型做深度分析（不填 Key 则完全离线）
  • P0 / P1 / P2 分级防护建议
  • 报告导出 TXT / HTML

运行与构建

运行环境Windows 10 / 11 x64，双击即用
联网方式默认完全离线；仅当你填入大模型 API Key 时才联网
分析对象只分析你自己输入的信息
源码fox_scout_pro.py（单文件，PySide6）
打包GitHub Actions 在真 Windows 上构建 EXE
